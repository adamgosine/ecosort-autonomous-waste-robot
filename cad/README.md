# CAD Models

The full Fusion 360 / AutoCAD models for EcoSort live in the team's Google Drive (NYU Tandon coursework constraints). This folder is a placeholder for the exported STL files of the 3D-printed components.

## Components

- **Scoop** - dustpan-style front collector, printed in PLA
- **Arm extensions** - link the scoop to the DS3225 servo motors, printed in PLA with reinforcement holes
- **GreenStart emblem** - team logo, designed in AutoCAD and printed at NYU OpenLab Protolab

To request CAD files, contact the project team.
